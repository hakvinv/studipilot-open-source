# Status

Die öffentliche Fassung ist ein Entwicklungsstand aus einem persönlichen StudIPilot-Projekt. Die private Installation und ihre Betriebsdaten werden hier nicht veröffentlicht. Die README beschreibt den ursprünglichen Einsatz; Aussagen zum laufenden Betrieb beziehen sich auf diese persönliche Installation und sind kein Nachweis für eine andere Einrichtung.

Für eigene Installationen sind Dienste und Zugangsdaten individuell einzurichten. Die öffentliche Fassung enthält keine persönliche App-Bindung und ist kein vollständig automatisiertes Installationspaket.

Die Offline-Tests lassen sich mit `python scripts/check.py` ausführen; Abhängigkeiten stehen in `remote-rag/requirements.txt` und `uni-gateway/requirements.txt`.
